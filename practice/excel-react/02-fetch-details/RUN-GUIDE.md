# Run this exercise

Open a terminal and paste:

```powershell
cd D:\Antigravity\Karat\practice\excel-react\02-fetch-details
npm.cmd run dev
```

Open the Local URL printed in the terminal. Do not double-click index.html.

- Edit App.jsx and save to update your output.
- Syntax errors appear in the red Vite overlay in the browser and in the terminal.
- Rendering errors appear on the page.
- Press F12 and select Console for console.log output, warnings, and network errors.
- The supplied exercise can contain errors: repair those in App.jsx.
- /?solution=1 shows the answer.
- Keep the terminal running. Press Ctrl+C to stop.

Dependencies are shared with the main Karat folder. If Vite cannot be found, run npm.cmd ci in D:\Antigravity\Karat once, then retry this command.
